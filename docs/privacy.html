Privacy Policy

Lybloo Autopost is an internal tool used only by Lybloo (lybloo.com) to share Lybloo's own products on Lybloo's own social media accounts. It is not offered to the public and has no users other than Lybloo.

What it accesses

With the account owner's permission, the tool uses the TikTok account's basic profile (to confirm which account is connected) and uploads product videos to that account's drafts. It reads product names, photos and prices from the public lybloo.com store.

What it stores

It stores only the login token TikTok issues, encrypted, so it can keep uploading drafts, and a list of which products were shared. It does not collect, sell or share personal data about anyone.

Removing access

The account owner can disconnect the tool at any time in TikTok under Settings and privacy → Security and permissions → Apps and services permissions.

Contact

Questions about this tool can be sent through lybloo.com.
